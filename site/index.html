Drawbridge

Drawbridge

An MCP gateway that treats every tool result as untrusted, and asks you before an agent sends anything out.

Watch the audit replay View on GitHub

How it works

1

Gateway

One process sits between the agent and every MCP server. Stdio in, a namespaced catalog out.

2

Policy, taint, and wrap

First-match policy decides the scanner. Untrusted results come back between <<untrusted>> and <<end untrusted>>, and the session is tainted.

3

Approvals

After untrusted content, a send waits for a person. Approve once, or deny. Unanswered calls are denied after 120 seconds. Approvals are once-only.

4

Audit chain

Every event is hashed to the one before it. The in-browser replay recomputes the chain from a JSONL log; nothing is trusted just because it is on disk.

Quick start

Install, build, and run the local demo. The config below is trimmed from examples/drawbridge.yaml. The README has the full file and the demo script.

Install 
pnpm install
pnpm build
pnpm demo
examples/drawbridge.yaml 
# examples/drawbridge.yaml
# Credentials use env: or file: refs.
scanner:
  mode: wrap
upstreams:
  notes:
    command: ["node", "examples/demo-upstream/dist/index.js"]
    trusted: false
  mail:
    command: ["node", "examples/demo-upstream/dist/index.js", "mail"]
    trusted: true
