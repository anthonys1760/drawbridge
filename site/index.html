Drawbridge

A gate in front of the tools.

Drawbridge is an open-source MCP security gateway. An agent connects to it over stdio. Drawbridge connects to the upstream servers you list, shows one namespaced catalog, checks each call against policy, and writes a hash-chained audit log before anything is forwarded.

Repository Apache-2.0

Architecture

One process between the agent and its servers.

Allow and the gateway Held or tainted Deny or a broken chain

Install

Node 22 and pnpm 10.

  1. Install and build from a checkout of the repository.
  2. Serve the example config. Stdout is the MCP stream. Logs go to stderr.
  3. Verify the audit log after a session. A rewritten or dropped line fails the check.
pnpm install
pnpm build
pnpm demo

pnpm demo reads the sample note, taints the session, and holds mail__send. The read-only audit replay is on this site. It checks the hash chain in the browser.

Point a 2026-07-28 client at that command. Tools are named upstream__tool, for example notes__read.

Roadmap

Milestones 1 through 6.

  1. M1 done
    Pass-through proxy

    Namespaced catalog and a write-ahead hash-chained audit log.

  2. M2 done
    Policy engine

    Allow, deny, and approve rules, argument checks, rate limits, flows, and tool pins.

  3. M3 done
    Scanner and taint

    Heuristics on descriptions and results, wrap / warn / block, and session taint.

  4. M4 done
    Approvals

    Elicitation, CLI, and dashboard. A held call waits for a person. Approvals are once-only in v0.1.

  5. M5 done
    Secrets and the threat model

    Per-upstream credentials, no client-token passthrough, a kill switch, and docs/threat-model.md.

  6. M6 done
    v0.1

    Attack suite and scored results. The static audit replay is part of this site.

The replay is a read-only view of an audit log. Open it from this site. It does not call the network.
